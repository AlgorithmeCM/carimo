# CARIMO SkinMatch AI — Brand alignment v1.2

## Why this revision exists

The first interface used a generic beauty-tech direction with translucent panels, pastel gradients and heavily rounded cards. This revision brings the demo much closer to the visual language used by CARIMO EMPIRE’s current storefront.

## Main changes

- Rebuilt the header around a CARIMO crown wordmark treatment and the slogan “L’audace d’être soi”.
- Replaced the pastel palette with a controlled CARIMO palette: black, white/ivory, metallic gold and bright fuchsia.
- Added a black announcement bar and a direct Shop action, consistent with an e-commerce storefront.
- Replaced pill-heavy controls with sharper, more editorial buttons and bordered panels.
- Added gold separators, restrained shadows and fuchsia conversion accents.
- Redesigned the landing preview, analysis panels, questionnaire, result dashboard and footer.
- Replaced generic product illustrations with live CARIMO product photography.
- Added hover treatments that resemble product-grid behaviour rather than a SaaS dashboard.
- Kept complete Arabic RTL support and all English/French/Arabic content.

## Product images

The demo uses product images hosted by CARIMO EMPIRE. For a production launch, these should be synchronized from the store API or copied into an approved CARIMO-owned media pipeline rather than maintained as hard-coded URLs.

## Validation

- TypeScript/TSX syntax transpilation passed for the edited files.
- The JSON translation files remain unchanged and valid.
- A full dependency installation/build could not be completed in the isolated environment because npm registry access timed out. Run `npm install && npm run build` on a connected machine before deployment.
